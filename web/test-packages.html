  • 2460、5213、7 款 D76 和 7 款风格滤镜采用 ISP 拟合配色；颜色可能与原 CPU LUT 不同。

测试前请了解

  • 5207 / 5219 的慢回放、即时回放无效果和连拍黑屏尚未确认修复。
  • 自定义 LUT 仍由 CPU 处理，普通胶卷异常回退仍保留；本包关闭日志，不写入 HDF／通用光晕扩展。
  • 不适用于 GR IIIx、GR II、GR IV。已有机内设置优先，请先阅读包内说明并确认各效果开关。
  • 固件沿用 2.10 版本号。同版本更新若被相机拒绝，请反馈提示，不绕过校验。
