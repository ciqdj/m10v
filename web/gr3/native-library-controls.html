机内怎么换卷？
  1. 按相机原厂流程安装此测试候选。先保留官方原包。
  2. 打开 MENU → 影像控制列表（非 ADJ 快捷列表），选择 M10V Library。
  3. Choose Slot 选择 Slot 1–5；再到 Choose Film 选卷并按 OK 确认。
  4. Grain / Soft Diffusion 调质感；Timestamp 配置日期、位置、颜色。
  5. Back 返回，Done 退出。若提示 Save failed，请勿继续拍摄验证，先记录现象。

800T、胶卷库、颗粒、时间戳与影像设置中选择的画幅、水平仪、负片颗粒会合入同一固件。胶卷效果仅处理 JPEG；在影像方案中启用 RAW 降噪策略后，会另外调整写入 DNG 前的 Bayer 降噪。内嵌 JPEG 预览可能带胶卷效果。
