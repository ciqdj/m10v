m10v·SD 胶卷库
固件工作台说明

GR III · FILMS TO GO

把胶卷库，带进相机。

将喜欢的胶卷装进 SD 卡，在机内随时替换五个影像风格槽。

需要配套的 M10V SD 胶卷库固件

本页仅支持 GR III 2.10。旧版内置胶卷库固件不读取 SD 文件，GR IIIx 暂不支持。独立胶卷库与水印交互已获用户真机确认；与主分支新胶卷融合后的完整固件经过离线回归。

胶卷效果仅作用于保存的 JPEG，实时取景尚不随换卷变化。 本版支持平台36款胶卷，包含800T、5207、蓝凤凰和哈曼 RED，并保留原厂详细调节；升级后请重新下载配套胶卷包。

前往固件工作台 →

01 / SELECT

选择胶卷

默认全选，也可只带走喜欢的几卷。卡上的胶卷数量不受五个活动槽位限制。

02 / LOAD

放进相机

  1. 解压下载的 ZIP，将 SD/M10V 文件夹复制到 SD 卡根目录，与 DCIM 并列。更新时只替换 FILMS.M10，保留其他文件。
  2. 机内进入 MENU → 设置 → 胶卷库，直接选择要替换的槽位并按 OK，进入卡上的胶卷列表。
  3. 使用 左右选卷、上下翻页，选卷后按 OK 装入，成功后返回五槽列表。MENU 返回上一级，五槽页按 MENU 退出。

时间水印：MENU → 设置 → 时间水印，机内选择关闭／仅日期／日期和时间，以及日期格式、四角位置、四种颜色。OK 保存，MENU 取消当前编辑。

800T：在影像控制中选中装有 800T 的槽位，按 FN 进入光晕强度、扩散范围、高光阈值、颗粒、柔光调节。装入成功后，重启或换卡仍保留。损坏、不兼容或保存失败时保持原槽；不会修改其他槽的质感和时间戳设置。
