m10v·SD 胶卷库
固件工作台说明

GR III · FILMS TO GO

把胶卷库，带进相机。

将喜欢的胶卷装进 SD 卡，在机内随时替换五个影像风格槽。

需要配套的 M10V SD 胶卷库固件

本页仅支持 GR III 2.10。旧版内置胶卷库固件不读取 SD 文件，GR IIIx 暂不支持。当前为离线验证候选，尚待真机验收。

前往固件工作台 →

01 / SELECT

选择胶卷

默认全选，也可只带走喜欢的几卷。卡上的胶卷数量不受五个活动槽位限制。

02 / LOAD

放进相机

  1. 解压下载的 ZIP，将 SD/M10V 文件夹复制到 SD 卡根目录，与 DCIM 并列。更新时只替换 FILMS.M10，保留其他文件。
  2. 机内进入 MENU → Image Control → M10V Library，通过 Choose Slot 选择要替换的槽位。
  3. 返回库菜单，进入 SD Film Library，使用 Previous page / Next page 翻页，选卷后按 OK 装入。Back 返回，Done 退出。

装入成功后，重启或换卡仍保留。损坏、不兼容或保存失败时保持原槽；不会修改其他槽的质感和时间戳设置。
