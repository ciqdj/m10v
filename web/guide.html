使用说明

使用说明

M10V 帮你建立自己的影像方案，将喜欢的胶卷与质感设置写入对应机型的固件。

关于 M10V

M10V 是 GR 固件定制工具，名称来自 GR III 内部 Linux 系统的主机名 m10v。

支持哪些相机？

首批支持 GR III 与 GR IIIx，共用一个工作台，导入后自动识别机型。当前核验样本为 GR III Street Edition 2.10 与 GR IIIx 1.60；其他型号和版本暂不支持。

怎么使用？

  1. 导入固件：选择对应相机的官方 BIN，或使用工作台提供的官方样本。核验完成后进入设置。
  2. 设置方案：先选槽位，再选胶卷，调整GR III 原厂颗粒和时间戳；800T 与蓝凤凰另有光晕，哈曼 RED 可调整模拟曝光 EI。胶片模拟与胶卷库共用五槽配置。
  3. 保存固件：核对机型和方案，阅读并确认风险提示。生成完成后下载固件，并保留官方原包。

GR III 导出为 fwdc239b.bin，GR IIIx 导出为 fwdc243b.bin。将对应文件放入 SD 卡根目录，通过相机的官方固件更新入口进行测试；是否接受该修改包仍需实机验证。

GR III 桥接测试套件

用户原图记录 DSP 2.10.32.27，高于旧包 2.10.22.27；新版桥接为 2.10.33.27，仅增加第三段，完整刷写待实机验证。查看桥接状态。

旧版 2.10.22.27 应停止使用；新版先完成桥接并重启，再刷套件内官方 2.10，第一阶段失败不要继续第二阶段。

GR III 通用光晕

在工作台的影像方案中选择是否写入光晕，默认不写入。写入后仍默认关闭：在机内图像控制中选中胶卷，按 FN 进入详细设置，光晕模式为 0 关闭、1 高光溢出、2 横向拉丝；强度、范围、高光阈值按胶卷保存。

全部内置胶卷及自定义 LUT 均支持。800T 的高光溢出保留原专属红晕，蓝凤凰保留原较弱橙红模拟；横向拉丝不叠加专属溢出。效果只处理静态 JPEG，不显示在实时取景中；开启可能增加保存与回放等待。仅 GR III 开放此通用模式，GR IIIx 保留既有专属光晕设置。

胶卷与质感

  • 46 套内置胶卷、5 个槽位：网页选择和机内换卷使用同一目录，胶卷图标随所选胶卷切换。无需 FILMS.GRF 或外部图片文件。
  • 颗粒：每槽独立设置关闭、弱、中、强；HDF 柔光使用独立的全局菜单。
  • 800T：GR III／GR IIIx 选择 800T 后，在【图像控制】按 FN，使用中文菜单调节光晕强度、扩散范围、高光阈值、颗粒。前三项为 0–8；颗粒为关闭、弱、中、强。关闭光晕后，颗粒和时间水印仍独立工作。
  • 时间水印：影像方案统一设置日期时间、胶卷名称、格式、位置和颜色，机内也可调整。机内通过 MENU → 设置 → 胶卷名称水印单独开关照片名称，时间水印菜单设置日期时间、格式、位置和颜色；日期时间使用相机时钟。
  • 导入 LUT：SD 胶卷库可输入名称并导入 sRGB 3D .cube，生成配套胶卷包；机内装卷后作用于保存的 JPEG。自定义胶卷与固件必须使用同一次配套版本。

胶卷效果作用于保存的静态 JPEG，取景画面和机内 RAW 再开发暂不支持这些效果；不保证与其他实现的成像逐像素一致。

首次没有有效 M10V 设置记录时使用网页配置；已经保存过机内设置时，已有记录优先。网页设置不会自动覆盖已有机内记录。

GR III 与 GR IIIx 现已开放相同工具，并分别保留机身型号、版本及 CPU 固件。胶卷库可与时间戳、画幅、水平仪、负片颗粒及 RAW 降噪合入同一固件。

GR III A/B 快切

GR III 2.10 可在 MENU 或 ADJ 的「影像控制」中按 DISP，直接从原厂风格与已装胶卷列表选择：按 OK 选 A，再选另一个风格并按 OK 选 B，自动返回取景。可以配对彩色与高对比度黑白。

取景时短按 DISP 在两种正式风格间切换，不叠加名称、图标或 A/B 提示；Fn 继续使用原有功能。普通影像控制选择风格并按 OK 可停用快切，或在 A/B 选择页松开入口 DISP 后再短按 DISP 停用。MENU 可取消选择；重启后保留配对，快切默认关闭。

GR III 两档裁切焦距

启用胶卷库并更新固件后，在 MENU → 设置 → 自定义裁切焦距中，上下选择第一档或第二档，OK 编辑，左右按 1mm 调整（28–100mm），OK 保存，MENU 取消。默认 35mm／50mm，原有裁切操作仍切换关闭和两档；关闭为 28mm。这是数码裁切，GR IIIx／GR IV 不启用此项。已做离线验证，实际成片与重启保存仍待机身验收。

独立 HDF 模拟

普通 GR III 可在工作台的影像方案中启用 HDF 模拟，单独使用或与胶卷库组合。机内入口为 MENU → 设置 → HDF 模拟，独立保存开关与档位，不随换卷或胶卷重置改变。数字柔焦作用于静态 JPEG，成像仍待实机验证。

刷机风险

这是非官方修改固件，刷入可能导致相机无法启动、数据丢失或设备损坏（变砖）。可能需要维修，且无法保证恢复。

旧版 GR III 桥接实机失败；新版修正版本准入范围，仍待实机验收。生成成功不代表全部使用场景均已验证。

请先备份照片、设置与官方固件，确认机型及版本匹配，保持充足电量，再自行评估是否刷入。工作台只生成文件，不自动刷写相机。
