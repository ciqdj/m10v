# D76 expansion implementation plan

> Execute inline with superpowers:executing-plans. User has specified exact identities, order, and approved the approximation boundary.

**Goal:** Add seven distinct monochrome stocks after T-Max 100 without changing existing film identities or saved slots.

**Architecture:** Reuse the existing 15-level RGB tetrahedral JPEG renderer, two bounded immutable LUT banks, native preview surrogates, and flat ten-card camera browser. New IDs are 299..305. Reference LUTs remain display interpretations, never measured physical-film calibration.

**Tech stack:** C/ARM, Python scientific tools offline, standard-library production verification, Node/browser modules.

**Spec:** User request and confirmed choices: Tri-X 400, Ilford Delta 100, Ilford Pan 400, Rollei Infrared 400, Ilford SFX 200, Fomapan 400, CatLABS X Film 80; CatLABS MKII; filtered infrared style approximations; original approximations permitted when exact licensed community LUTs are unavailable.

## Constraints and review focus

- Preserve all existing 30 output LUTs, names, order within groups, 184-byte state ABI, custom IDs 79..288, and old SD packages.
- Preserve original ROM budget and stock resource pointers; all seven ADJ icons must reach stock width/height/draw APIs.
- Exact names remain unchanged; approximation information is separate metadata/copy.
- Mono JPEG output must have equal RGB channels, finite bounded values, monotone grey ramps, and independent stock tables.
- Native preview fits do not authenticate completed JPEG color; JPEG always uses the full LUT.
- Four-page navigation must handle the final seven cards, cancellation, direct shooting exit, no-card and corrupted-record cases.
- No scientific fitting dependency may be needed on the server.
