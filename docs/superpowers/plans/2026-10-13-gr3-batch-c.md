# GR III 第三批处理链 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 整合柔光/800T/时间戳，新增RAW NR策略及已证明的更多画幅。

**Architecture:** 使用A配置和B扩展分配，一个捕获入口处理空间效果；NR与画幅各自生成可解释补丁，不放宽全部审计白名单。

**Tech Stack:** C/ARM、Python、Node、Web Worker。

**Spec:** [设计§7/9/10](../specs/2026-10-13-m10v-gr3-three-batches-design.md)

## Global Constraints

继承[总览](2026-10-13-gr3-three-batches.md)。现有800T区域不能继续追加代码；soft/halation/timestamp必须共用新布局。先证明再开放新画幅。

## Review Focus

双效果种子污染/部分像素处理/RAW别名由C1覆盖；NR量化与双变体由C2；半配置LV模式、画幅各消费者与时间戳越界由C3覆盖。
