# GR III 第一批与编辑基础 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 接入原厂名称/图标、负片颗粒、逐胶片颗粒，交付稳定异步编辑基础。

**Architecture:** 新规范化配置和补丁账本包裹旧五槽运行时；独立验证从获准配置推导预期。稳定DOM和Worker预览替代主线程重建与像素运算。

**Tech Stack:** Node ES modules、Python 3.12、ARM探查、Web Worker、现有本地服务。

**Spec:** [设计§4/5/9/10](../specs/2026-10-13-m10v-gr3-three-batches-design.md)

## Global Constraints

继承[总览全局约束](2026-10-13-gr3-three-batches.md)。本计划不执行B/C的未验证补丁。
