# 漫画与 E6 滤镜设计

状态：2026-10-27 用户确认按此方案实施；本地候选已完成相关离线检查，等待用户实机验证。基线：GitHub main `9ae4cf5c3fea4e02cc43521c1c679da002eb186b`，当前独立工作树、分支 `daily/anime-e6-isp`。

## 用户已确定的需求

- 「创意」增加 Makoto Shinkai、Ghibli、1970s；1970s 是用户指定的展示名，以其提到的复古日漫观感为方向，不自行改名。

- 默认优先 ISP 性能；只有漫画进阶开启时允许 CPU 空间处理。
- FN 参数面板支持线稿、色块、手绘；注意样式，中文不能超长。

## 方案与边界

用户选择默认 ISP 配色、进阶显式选择 CPU 的方案。全时 CPU 调色违反默认性能要求；全 ISP 线稿/手绘目前缺少已验证硬件接口，不能以锐度或颗粒参数冒充。默认使用离线拟合的 ISP 矩阵、256 点曲线、分色区参数，不在相机现场解析或拟合 LUT。进阶模式先完成同一 ISP 配色，再对 JPEG 的已归属图像执行明确选择的空间效果，不重跑 CPU 色彩 LUT。

Velvia 使用已有稳定 ID 294，恢复到可选 E6 目录，保留其身份与旧包兼容。六个新身份暂定 306..311：306 Makoto Shinkai、307 Ghibli、308 1970s、309 Fuji Provia 100F、310 Kodak Ektachrome E100、311 5294；实施前复核全库无占用。展示顺序和稳定 ID 独立。

## 风格来源与验证

Velvia 50 已有同名社区 LUT 和来源许可证。Provia 100F、E100、5294 分别查找同型号来源，不把 Provia 100、E100G/GX、5285 或电影印片 LUT 当成对应型号。官方特性曲线/光谱资料与社区 RGB LUT 分别记录用途、版本、URL、许可证及哈希。没有确切可用社区 LUT时，记录缺口与独立建模假设，不伪造官方变换。动漫名称对应配色方向，没有唯一官方 RGB 参数或可承诺逐场景还原的标准。

对实际量化 ISP 模型使用独立留出集报告 ΔE00 中位数、P95、最大值与灰阶/极值行为；这些是对目标变换的拟合误差，不是对实物胶片或漫画作品的还原百分比。尽量让网页默认预览与量化 ISP 目标一致，明确进阶效果与机内取景的差异。默认不额外开启颗粒、光晕、HDF 或水印。

## FN 与参数保存

只在三款漫画滤镜的 FN 参数中增加一行「漫画进阶」。同一行可选「关闭 / 线稿 / 色块 / 手绘」，默认关闭；选择后三项即显式开启进阶空间处理。三个模式互斥，避免增加多行开关和组合状态。耗时提示「开启后处理较慢」放在网页与随包说明；FN 保留短标题及四个短选项，不将长说明塞进参数行。实施时发现 ROM 增长约束，因此标尺复用原厂 400px 宽与 10px 辅助字号；参数值字形保持 14px，实际值区仍为 40px。

沿用原厂行高、字体、选中背景与左右边距；检查四个值的正常/选中态、返回和取消行为。官网网页参数使用相同语义。其他胶卷不显示此项。用每槽 effects 的既有保留字节按胶卷身份解释新模式（具体字段由实现者核对所有消费者后确定），保持 state 大小与存档版本；其他身份的该字段契约不变。旧存档解读为关闭，模式变化原子保存，失败不激活。换卷、重置、SD 快照、构建配置、网页草稿与逐张冻结快照保持一致。

## 进阶空间处理

线稿：从亮度邻域提取边缘并叠加描线，保留底层动漫配色。色块：限制色阶以形成平涂观感。手绘：局部保边平滑、色阶和柔和轮廓的传统图像处理近似；不声称语义重绘或 AI 生图。使用有上限的行缓冲/小块工作区，不分配整图临时副本；保留 stride padding、chroma 对齐与 RAW 归属检查。关闭时必须完全跳过 CPU 图像访问与空间缓冲申请。

参数按曝光的本张快照冻结，不读取 UI 最后选择；多张排队及更改模式不得改写已曝光照片。ISP 完成标记只认证真实本张色彩阶段，不能吞掉已选择的进阶阶段；主图/缩略图别名不重复执行。内存或归属验证失败不执行不安全像素操作，不伪报进阶已完成。

## 机型与保护范围

优先证明 GR III 2.10 的现有 ISP 实拍入口。IIIx 共享消费者必须验证其自身映射与接入，不能照搬 III 地址或默许落到 CPU 调色；未证明的机型明确拒绝导出新效果。GR IV/II 不扩张支持承诺，保留已有机型边界。历史胶卷 ID、custom 79..288、现有十槽、状态 ABI、其他 FN 项、水印/HDF/颗粒/光晕、A/B、RAW 安全及原厂工具不因本次变更删减。

## 验收与交付

1. 目录/图标/网页/SD 合同一致，原有包仍可读；坏记录拒绝且不污染其他槽。
2. 七款默认配置必须由真实原厂任务生产者经过 Still Make、完成校验到编码桥；24MP 像素未映射，任何 CPU 像素访问、整图临时分配或文件服务均使测试失败。
3. 进阶三个模式有可见且不同的输出；关闭不改像素，参数冻结、主缩略图别名、边界尺寸、stride、RAW-only 与 RAW+JPEG 安全测试覆盖。
4. FN 原厂资源与实际字形/排版检查，四个短选项不截断、不重叠；不能只通过字符串长度断言判断布局。
5. 使用现有导出链构建候选，保存源/配置指纹、build_id、BIN/ZIP/SD 包哈希和恢复说明；不含官方固件或照片的公开提交。
6. 交付相关离线回归与明确的实机清单；默认与原厂正片/负片对照即时回放、相册及至少连续三张；进阶单独测处理时间。未取得当前候选设备验收前不合并 main、不推送、不部署。
