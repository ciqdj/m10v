# 自定义 SD LUT 与时间戳入口设计

日期：2026-10-20。状态：设计已在对话中确认，待书面规格审阅。

## 目标与范围

用户在 GR III / GR IIIx 的 SD 胶卷库网页输入名称并导入 3D `.cube`，将它与选中的内置胶卷一起导出。相机从 SD 卡选择自定义胶卷装入五个活动槽之一；拍摄保存的 JPEG 应应用其色彩变换。已成功装入的槽在重启、拔卡和换卡后仍可使用。网页上的时间戳配置只在影像工具台出现；相机继续通过机内“时间水印”菜单调整同一份全局设置。时间水印增加独立的“胶卷名称”开关。

取景实时预览、RAW 像素和机内 RAW 再开发不在本次范围。相机接受固件和实际成像须经实机验证；离线测试只产出候选。

## 现状与约束

当前 `FILMS.M10` v1 使用 4096 字节头和定长 12288 字节记录。机内只接受 ID 33–72，并用固件编入的 40 份 SHA-256 校验完整记录。现有记录中内置 LUT 只保存身份摘要，不携带任意色彩表。机内五槽状态保存胶卷 ID，已选内置记录另存为 12288 字节快照；拍摄路径按 ID 查找固件内的渲染器。现有网页胶卷控件包含时间戳设置，影像工具台也提供时间戳入口。

因此不能仅在网页追加文件选择框。包验证、记录持久化、五槽身份、菜单名称和 JPEG 色彩路径必须一起升级，并维持当前构建的固件大小、来源校验和运行时预算门槛。

## 方案选择

采用版本化的自有数据包，导入时将 3D LUT 采样为机内可用的定长 RGB 表，随名称、图标和校验写入包。装卷时从 SD 读取并校验完整记录，保存到机内，随后只从已保存的数据渲染 JPEG。相比拍摄时读卡，这能保持已装胶卷脱离 SD 卡工作；相比把 LUT 编入固件，新增胶卷无需重新构建固件。保留既有 v1 包识别供内置胶卷使用，但新自定义记录必须由配套新版固件解释，旧固件应明确拒绝。

## 网页与输入契约

在 SD 胶卷库增加“导入 LUT”区：输入名称、选择 `.cube`，成功后显示可选择的自定义胶卷卡片，支持移除和重复导入。导出仍是一次 ZIP 下载，包含 `SD/M10V/FILMS.M10`、清单和操作说明。名称做长度、字符集和重复检查；页面以文本节点渲染，不执行文件内容。LUT 解析只接受完整的 `LUT_3D_SIZE`、有限数值、合法行数及明确的 sRGB 输入约定；空文件、超限文件、1D LUT、非有限值或格式不完整均拒绝。现有本地 `fitCube` 可作为解析参考，但不得把它拟合出的原厂参数当作精确 LUT。

记录采用 13³ RGB8 采样表（6591 字节），从合法 3D LUT 三线性采样得到；导入确认时说明高分辨率源 LUT 会下采样，提供导出前的网页预览。按固定 12288 字节记录布局编排名称、类型、表、图标、版本和校验，不把源 `.cube` 原文送入相机。自定义 ID 使用独立于 33–72 的稳定内容身份；重复名称或相同身份冲突时阻止导出。包最多 256 条，大小与整数运算继续受头部和文件大小上限约束。

## 机内包、槽位与渲染

新版包显式声明记录类型和渲染版本。内置记录继续按固定可信摘要校验；自定义记录校验结构、长度、名称、13³ 表、内容摘要和 CRC，拒绝越界、重复身份及未知版本。CRC 用于损坏检测，不作为来源认证；自定义 LUT 视为用户数据，只能影响色彩查表，不得携带代码或地址。

装卷先将完整记录读入临时缓冲，完成校验和渲染资源检查，再保存该槽的自定义快照并回读。只有快照可用后才提交五槽状态；任一步失败维持原槽。已有内置胶卷快照和旧状态迁移继续可读。菜单列表显示自定义名称，并为其生成或携带固定尺寸图标。拍摄时不访问 SD、不解析文本；从已验证快照读 LUT，以现有 JPEG 处理阶段完成三线性采样，后续颗粒、漏光和全局时间戳照常执行。若快照缺失或损坏，安全回退原槽或阻止该自定义槽生效，不用错误表处理像素。

机内持久化路径必须验证 AppData 文件容量、写入回读语义以及五份自定义快照对空间的影响；若无法在既有预算内可靠保存，不能生成标称支持自定义 LUT 的可刷固件。GR III 与 GR IIIx 分别验证 ABI、菜单、预算及构建产物，不能以一款机型的地址推断另一款。

## 时间戳统一

影像工具台作为网页唯一入口，显示关闭、日期、日期时间及格式、位置、颜色，以及独立的“胶卷名称”开关。从胶卷库编辑器移除重复控件；SD 胶卷库页面只说明机内菜单位置。机内“菜单 → 设置 → 时间水印”增加同一开关，设置与换卷相互独立。名称开启时即使日期关闭也绘制；日期与名称同时开启时名称在日期下方，同角落、颜色、比例和暗色描边。内置胶卷使用当前槽名称，自定义 LUT 使用装卷时保存的名称。扩展原有 5×7 字形以覆盖允许的名称字符。文本超出图像安全区域时跳过名称，日期可继续绘制。无效相机日期只阻止日期绘制，不阻止名称绘制。旧机内记录和网页草稿迁移时名称默认为关闭，保留既有时间戳字段与五槽值。

## 验证与交付门槛

先定义 Node/C 共用的包向量，再覆盖合法 LUT、截断、超限、重复 ID、损坏校验、未知版本、短读、拔卡、保存失败及断电恢复。验证内置 40 款和旧包兼容、五槽逐槽替换与重启加载、时间戳迁移、胶卷名称在日期开关两种状态下的绘制、无效日期时的名称绘制、颗粒和漏光组合。对 JPEG 路径做像素参考比对及性能/内存预算检查；独立回读最终固件、改动地址、校验和与分区。最后在两款相机上检查安装、菜单、换卡、实际 JPEG、RAW+JPEG 和失败回退。未通过实机验证时只标为测试候选，不宣称相机效果已验证。
