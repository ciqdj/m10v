# GR IV / GR II 原生工作台移植设计

日期：2026-10-14。状态：范围已确认，具体设计待审阅。

## 目标与范围

用户要求仔细逆向根目录 bin 中新增的 GR IV、GR II 固件，复刻现有 GR III 工具，并已确认按 GR IV → GR II 的顺序推进。

目标是在同一个工作台完成导入识别、五槽胶卷配置、机内菜单、65 款胶卷目录与图标、每槽颗粒和柔光、800T 光晕、相机时钟时间戳、修改固件导出与独立回读。现有 GR III / IIIx 行为需保持兼容。原厂参数编辑、名称图标、画幅、水平仪、RAW 降噪等工具逐项调查与原 GR3 工具对照；未证明的功能在能力表中明确禁用，不以通用界面代替固件实现。

静态 JPEG 是胶卷处理目标。取景、视频、RAW 再开发不纳入本次胶卷处理接入。RAW CFA 像素必须保持原始路径；DNG 内嵌预览另行报告是否经过处理。

## 方案选择

采用共享算法与配置、独立机型固件适配层。相比复制整套 GR3 工具，这能复用目录、编辑状态和图像算法，同时让地址与 ABI 证据保持机型独立。相比先把参考 GR4 编辑器单独开放，该方案直接服务统一工作台与 GR3 功能复刻；参考编辑器作为已有解析与资源研究基础。

不进行 GR3 代码地址整体平移。现有 native/gr3/m10v_library_camera.c 和 m10v_library_capture.c 中的文件系统函数、RAM 范围、拍摄上下文、Y/C 缓冲描述符、色调字段均依赖 GR3 2.10。每项在新机型上必须重新建立调用契约。

## 模块与数据流

1. 保留现有机型适配器注册机制。每款机型提供严格识别、只读检查、能力、草稿验证、构建和回读验证。GR II 在解析证明完成前仍不可构建。
2. 为每款机型记录独立的输入身份、分区身份、加载映射、补丁地址、原始指令、函数签名及证据位置。写入前校验完整输入身份与每处原始字节，遇到差异中止。
3. 共用胶卷目录与语义配置，不直接沿用 GR3 的色调编号、像素格式、图标编号或资源尺寸。机型适配层负责转换；色彩参数需按该机型管线校准，不能因名称相同宣称成像相同。
4. 机型原生模块分别处理菜单、图标、持久化、时钟和 JPEG 桥。纯图像算法及状态校验可复用；包含固定地址的文件保留在各自机型目录，避免影响现有 GR3 构建及来源校验。
5. 导入 → 精确识别 → 解包核验 → 显示能力 → 保存草稿 → 编译适配运行体 → 校验补丁原像 → 重打包 → 独立回读与审计 → 用户下载。现有保存确认流程继续使用。

## GR IV 研究与实施顺序

先以现有 codec 与 firmware 解析器生成可复现的分区、版本、资源清单；建立原样重打包和解码后字节一致性检查。参考核心中已有色彩表入口、槽位及菜单资源研究，可用于定位线索，须核对官方输入中的指令与实际引用关系。

随后定位菜单枚举、名称、图标及资源访问，建立五槽与完整目录的入口。定位相机设置存储接口，验证读取、写入、回读、断电记录选择及错误返回。再沿静态拍摄调用链定位 JPEG 编码前缓冲，证明尺寸、步长、格式、缓存、内存分配、生命周期以及 RAW 区间；接入算法与时钟。运行体注入位置必须核验加载映射、空间与分支距离。

每项功能分别拥有证据与测试，再接入统一工作台。现有 GR4 crop/shutdown 参考路径与新增胶卷路径的组合只有在补丁区间及运行体空间审计通过后才开放；否则明确互斥。

## GR II 研究与实施顺序

先解析 UNITY 文件头、记录边界、载荷长度、编码与校验。用头部字段和数据特征验证假设，不套用 RICOH BIN 的固定偏移。解包结果须有边界与一致性证明；原样重打包必须精确复原文件，或明确列出全部编码差异并证明解码内容、校验与记录语义相同。

然后识别可执行架构、加载地址、启动复制映射、资源与字符串引用，定位菜单、图像管线、存储和时钟接口。只有这些基础契约成立后才实现机型原生模块及功能接入。若固件采用尚未破解的编码或完整性机制，报告具体机制与证据缺口，继续可完成的只读分析，不输出声称可刷的占位文件。

GR II 下载名称必须由更新器与容器证据确认；目前不猜测，也不把 .frm 改名为 GR3 .bin。

## 验证与完成条件

- 容器：严格边界、长度、终止标记、校验、组件版本与分区身份；损坏输入和未知版本被拒绝。
- 构建：原样往返；变更局限于批准的功能区间；未修改组件保持一致；最终文件重新解包并独立读取配置、资源、运行体与补丁。
- 原生接口：对官方指令与新模块执行针对性 CPU 测试，检查寄存器、栈、调用约定、原函数链接、异常与取消路径。模拟测试的覆盖范围明确记录。
- 图像：已知缓冲验证五槽选择、颗粒、柔光、光晕、时间戳；边界尺寸、内存失败及不支持拍摄模式；RAW 区间保护与缓存调用。
- 产品：各机型导入、能力展示、草稿恢复、配置验证、取消构建、正确下载名及未知固件拒绝；回归现有 GR3/IIIx 相关检查。
- 文档：每款机型有可复现分析入口、证据报告、功能对照表、构建审计和实机验收步骤。

离线移植完成表示可重复构建且上述离线检查通过。刷入、启动、菜单交互、成像、断电持久化与恢复仍需真实相机验收，始终与离线通过分别标记。当前没有实机操作授权或已通过实机的证据。

## 执行边界

固件输入保持只读，研究输出与候选文件进入忽略的 data/builds 目录，不提交官方固件。自有适配代码和研究记录可纳入仓库；参考源码保留许可与来源。只提交本任务文件，不发布、推送或修改相机。
