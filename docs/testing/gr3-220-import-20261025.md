# GR III 2.20 import fix

Scope: official firmware import/inspection only. Native patch addresses, runtime compilation and camera flashing on 2.20 are not adapted or validated by this change. No firmware binary is committed.

Official source: https://www.ricoh-imaging.co.jp/english/support/digital/gr3_s.html

- Official SHA-256: `5c53760b3b564c87239dbf7f5c94d0f6fd91accd156ec4ba672ebfd6b861793e`.
- File: 30472516 bytes; decoded: 59798532 bytes; version: 2.20.20.28.
- Regression reproduced before fix: `size: unsupported firmware length`.
- Node focused tests: 3 passed, 6 fixture-dependent skips; real 2.20 fixture enabled.
- Python firmware tests: 1 passed, 5 legacy-fixture skips. Real 2.20 no-op repack is byte-identical.
- Separate real-sample checks: Node recognizes GR III 2.10 and IIIx 1.60; Python recognizes GR III 2.10 and no-op repacks it identically.
- Full npm suite: 195 passed, 84 failed, 36 skipped. Clean HEAD baseline: 194 passed, the same 84 failures, 36 skipped. Failure names compared after normalizing checkout paths: identical. Existing failures include missing root BIN fixtures and stale schema/catalog/UI expectations.
- No camera test, no 2.20 native firmware candidate generated.

To rerun the new tests, set `M10V_GR3_220_FIXTURE` to a local official 2.20 BIN and run `node --test node/firmware-220.test.mjs` and `python3.12 -m unittest tests.test_firmware`.
