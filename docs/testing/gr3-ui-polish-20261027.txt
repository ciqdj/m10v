安装与保留
1. 使用备用 SD 卡，先备份整卡及现有已验证固件。按既有 M10V 固件安装流程，将 gr3/fwdc239b.bin 放在卡根目录；不要将 runtime.bin 当作固件。
2. 保留卡上 M10V 配置和自定义胶卷。SD/M10V/FILMS.M10 是可选的内置库；有自己的 FILMS.M10 时先保留，不要直接覆盖。
3. 已存设置优先于包内默认值。HDF 功能已编入，默认强度 0；通用光晕已编入，默认关闭；调试关闭。
4. 更新后移走卡根目录升级文件，保留此包及 SHA256SUMS 用于核对身份。

重点实测
A. 影像控制 → 自定义胶卷 → 参数调节：光晕模式显示 0/1/2，标题为“光晕 0关 1溢出 2拉丝”。检查不截断、不显示省略号；切换关闭/溢出/拉丝，再调强度、范围、阈值和颗粒。800T、蓝凤凰及普通卷各测一次。
B. XPan 与 6×7：取景只保留系统框和裁切遮罩，不再重复加边线。切换网格、显示模式、裁切焦距、半按对焦；对照 3:2、1:1、4:3。拍摄 JPEG、RAW+JPEG，确认输出尺寸、回放和 AF 正常。
C. 设置 → 水印 → 日期时间 / 胶卷名称；设置 → 效果 → HDF。检查进入、取消、保存、返回、反复进入及重启；日期格式、位置、颜色仍可设置；胶卷名称与日期时间可独立开关。HDF 子页取消不保存，确认后返回“效果”。
D. 分别用原厂正片、自定义胶卷拍摄。回看并切换 DISP：自定义胶卷出现通用胶卷标识，参数面板不再空白，原厂照片保持原厂标识；切卷、重启后再看旧照片。私有照片历史只记录槽位编号，因此通用标识不声称恢复具体卷名。旧版替换原厂槽位拍摄的照片仍保留其原厂元数据标识。
E. 同场景对比原厂正片/负片：附加效果全关，检查首张、即时回放、相册、至少连续三张和 RAW+JPEG 文件数量。再分别开启光晕、HDF、水印检查成片与恢复；不以取景效果替代成片检查。
