# M10V GR III 原生胶卷库实机验收

这是相机尚未验证的独立候选。唯一官方基线：仓库 `fwdc239b-offical.bin`，GR III Street 2.10，SHA256 d6a3c9c288d784080e7b283222ecdd8752adfeed6faa36dab44f73115354bfd4。只适用于匹配的机型和版本；保留官方原包。没有自动刷机动作。

## 交付文件

`builds/m10v-unified/gr3/fwdc239b.bin` 是实际生成的候选；同目录保存 `M10V-build-receipt.json`、`M10V-runtime-manifest.json`、`M10V-configuration.json`。以 receipt 的 SHA256 核对 BIN，配置记录说明首次初始值。网页 `/gr3/` 在同一三步流程内重配并重新构建。GR IIIx 使用 `/gr3x/` 和 `builds/m10v-unified/gr3x/fwdc243b.bin`。

默认五槽胶卷：M10V Neutral、Amber Day、Cool Dusk、Warm Fade、800T。颗粒、柔光和时间戳初始关闭；先验证菜单，再逐项开启。所有 33 套胶卷随固件内置，不放置外部胶卷文件。网页默认只在没有有效 M10V 内部记录时使用，不覆盖之后的机内设置。

本候选和 800T 固件是独立构建，不能叠加使用。沿用官方版本号，设备是否接受同版本改包尚未验证，不用候选升级包处理失败的恢复。

## 机内流程

1. 按机型原厂升级流程安装候选，确认能进入拍摄。若相机拒绝包，记录提示，不尝试改版本号绕过。
2. 打开影像控制列表，在原厂条目后选择 **M10V Library**。
3. **Choose Slot** 选择 **M10V Slot 1–5**；随后进入 **Choose Film**，在 33 套中选卷，按 OK 确认。浏览不会写设置。
4. **Grain** 和 **Soft Diffusion** 分别提供 Off / Weak / Medium / Strong，影响当前槽位。
5. **Timestamp** 提供 Off / Date / Date + Time，并可进入 Format / Corner / Color；格式为 YYYY.MM.DD、DD.MM.YYYY、YYYY-MM-DD、YY.MM.DD。相机时钟须准确。
6. 列表末尾 **Back** 返回上一级，**Done** 退出。错误会显示 **Save failed. Try again.** 并保留菜单；写入未成功时，不应假定设置已生效。
7. 重新打开胶卷库可继续替换。普通影像控制五槽名称为 M10V Slot 1–5；没有宣称回放或 EXIF 显示每卷原创名称。

## 分步实拍

| 阶段 | 操作 | 需要记录 |
|---|---|---|
| 菜单 | 打开库、滚到第 33 卷、取消、返回、确认 | 所有条目可到达，确认有反馈，没有崩溃 |

| 柔光 | 高光边缘与暗部同框，四档各拍一次 | 高光向邻域扩散，暗部无异常块状变化 |

| 组合 | 粒度+柔光+时间戳一起开启 | JPEG 保存正常、效果共存 |
| 拍摄路径 | JPEG-only、RAW+JPEG、连拍各测 | 无卡死或漏存；保留 DNG 与 JPEG 原文件 |

当前效果只作用于保存的静态 JPEG，不预览于取景，不用于机内 RAW 再开发。各槽叠加自己的原厂影像控制，跨槽底色可能不同。DNG 原始像素不处理，内嵌 JPEG 预览可能带效果。设备持久化/缓存/菜单服务与耗时仍需真实相机结果。

## v2：统一目录与完整光晕控制

本次交付位置为 `builds/m10v-unified-v2/gr3/fwdc239b.bin` 和 `builds/m10v-unified-v2/gr3x/fwdc243b.bin`。65 卷均可装入五槽；菜单列表含 Back/Done 共 67 行。影像页和胶卷库对同一份配置编辑，选择 Ektar 100 等原模拟预设后可在机内 Choose Film 再换卷。

进入 **M10V Library → Choose Slot → 800T Halation**，分别打开 **Halation Gain / Halation Spread / Highlight Gate / Halation Profile**。前三项值 0–8，档位 Off / Weak / Natural / Strong。默认 3 / 3 / 5 / Natural。参数列表定位到已保存值。每槽独立保存；切换成其他胶卷不会应用红晕，但保留该槽的光晕参数。

分别验证：调整四项参数后拍摄、重启，再查看值；在五槽间切换确认各槽独立；Off 只关闭光晕，颗粒、柔光、时间戳仍生效。保存失败时保持旧值。旧版 44 字节记录的卷号、颗粒、柔光、日期及序号迁入 v2；新光晕值从默认起步。

32 条模拟预设的原矩阵和两组曲线数据已逐项无损回读，实际 ARM 色彩计算与主机 C 输出逐字节一致。新路径在 JPEG 上运算，旧 ISP 的颜色、取景及 RAW 再开发结果不宣称相同，需实机同场景对照。网页初始值仍只在没有有效机内记录时使用；已有机内设置优先。

## M10V cartridge icon build (2026-10-14)

The original M10V artwork is generated by `scripts/generate_m10v_icons.py`; it imports no third-party image assets. All 65 presets use 40×40 RGBA cartridges. 800T uses a red body. Web cards, the five-slot preview and camera sprites share the same decoded pixels.

The exact official 671-entry icon directory is preserved. New IDs 671–735 point to read-only descriptors and RGBA bytes in the appended RTOS. Three stock width/height/drawing lookups use the extended directory and bound 735. The drawing pointer shim distinguishes stock ICONBIN-relative offsets from private absolute ROM addresses, preserves registers and CPSR, and returns to the stock drawing path. The original ICONBIN section remains byte-for-byte unchanged. Five real tone slots resolve their saved journal film to the matching icon; changing a film does not change its grain, diffusion or halo settings.

The new runtime is 475,744 bytes, including 416,000 bytes of artwork. Its RTOS growth is 478,368 bytes. Native builds explicitly permit at most 512 KiB of growth and verify every covered startup identity mapping, including the second section; older generic candidates retain their default 64 KiB bound. Every original RTOS byte outside the 27 audited patches and all other firmware sections are preserved. These checks do not establish updater acceptance, later memory mappings or real-camera rendering.

Candidates are `builds/m10v-icons-v3/gr3/fwdc239b.bin` and `builds/m10v-icons-v3/gr3x/fwdc243b.bin`. These are experimental camera-test candidates. After updating, verify that the Choose Film list shows cartridge icons; select 800T and confirm its red icon in the selected slot. Select another roll, leave and reopen the menu, and power-cycle to check that the selected roll and icon remain consistent. Also check image-control menus and photographs with the existing grain, diffusion, timestamp and halo controls. A webpage refresh cannot add icons to an older installed firmware.

### Cartridge name labels (v4)

The cartridge face now carries the preset name or stock code instead of M10V branding. Names longer than five capitals are abbreviated for the 40px camera sprite; full names remain in the web cards and camera menu. Examples: CINE / 800T (red), KODA / 200 for Gold 200, and 5219 / 500T for V3 500T. The 5219 identification follows [Kodak's VISION3 500T product page](https://www.kodak.com/en/motion/product/camera-films/500t-5219-7219). These are label changes to existing presets, not newly introduced recipes. The palette and cartridge silhouette are retained. Website assets and embedded RGBA pixels are regenerated together.

Latest candidates: `builds/m10v-icons-v4/gr3/fwdc239b.bin` and `builds/m10v-icons-v4/gr3x/fwdc243b.bin`. Both use the unchanged menu/capture implementation and pass full candidate readback. Camera rendering still requires a hardware test.
