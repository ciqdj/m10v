## 实机测试

1. 按此前成功使用的刷机流程，将本包 fwdc239b.bin 放入存储卡根目录更新；保持电量充足，更新中不要断电。
2. 选择 800T，进入【图像控制】按 FN。确认五项中文完整显示，无乱码或截断。
3. 调节颗粒、柔光：左右各走到端点，确认仅有关闭、弱、中、强四个位置，光标与刻度对应，无多余空档。
4. 确认光晕强度、扩散范围、高光阈值仍可调 0–8。退出再进入，并重启，确认数值保持。
5. 拍一张此前正常的高光场景，确认红色光晕与偏青色调保持；分别切换颗粒、柔光的关闭与强，确认效果随参数变化。
