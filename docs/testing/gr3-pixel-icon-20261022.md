# 方块世界 ADJ 图标修复

基线：`0e3c3b93d467d0480e82b1d5cadcf2feda678cab`。用户报告 ADJ 缺少方块世界图标，并明确授权修复后直接发布 GitHub 与宝塔。

根因：图标目录已追加资源，但原厂宽高读取、绘制入口和 ROM 像素地址转换仍使用旧上限 754／760，拒绝新图标 755／761。修复同步这三处入口与指针转换的边界；不改变图标内容、胶卷 ID、成像和存档。

`tests.test_gr3_pixel_icon_arm` 在普通与 SD 胶卷库两种模式构建最终固件并解码 RTOS：执行实际宽高读取函数，验证新图标为 40×40、下一 ID 被拒绝、绘制上限、RGBA 数据及 ROM 指针转换；同时验证寄存器与状态标志恢复。修复前两种模式均返回 0 而失败，修复后通过。既有图标、五槽映射和 A/B 菜单另做相关回归。

本轮未进行机身实测，`camera_tested=false`；离线 ARM 检查不等同于机身验收。使用修复需重新生成并安装固件，仅更新 SD 胶卷包无效。
