# GR III 两档自定义裁切焦距

范围：GR III 2.10，保留两档裁切；每档可在机内按 1mm 调整为 28–100mm，并独立保存。原厂默认 35mm／50mm；关闭裁切仍为 28mm。这里是数码裁切，不改变镜头光学焦距。GR IIIx／GR IV 不启用此功能。

## 操作

MENU → 设置 → 自定义裁切焦距。上下选择第一档或第二档，OK 开始编辑，左右按 1mm 调整，OK 保存，MENU 取消本次编辑。两档可设相同数值。焦距数值会持久化；相同倍率的档位身份仅在当前运行中区分，重启后依据倍率恢复：两档相同值优先第一档，28mm 优先关闭裁切。回到原有裁切操作切换关闭、第一档、第二档。

保存采用两份带 CRC 的 24 字节 AppData 记录（M10VZA.bin／M10VZB.bin），成功写入并回读后发布；单份损坏优先恢复另一份，两份无有效记录则用默认值。读取失败或保存／应用失败会显示提示。

## 集成与验证边界

原厂连续倍率取景、AF 窗口与拍摄裁切窗口接收实际倍率。自定义 JPEG 尺寸按比例计算并向下对齐 16 像素，保留已有画幅和画质上限。照片记录拍摄时的自定义倍率，之后修改档位不重解释旧照片；原厂照片保留原逻辑。

持久化、两档身份、菜单控件、无效元数据、JPEG 几何和最终固件 Hook 通过 host／ARM 离线测试。测试包保留源代码快照、manifest、receipt 和 SHA256SUMS。检查命令与最终统计见本次发布记录。

机身开关机持久化、实际 JPEG／DNG 成片、连拍、历史照片回放及 AF 体验尚未真机验证。DNG 底层裁切参数到最终文件的完整数据链尚未闭环确认，不能把离线几何测试当作真机 DNG 验收。
