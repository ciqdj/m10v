## 改动与保留

| 路径 | 行为 |
| --- | --- |
| 精确官方 2.20 导入后的功能导出 | 原有胶卷/组件/图片独立审计后，追加更新兼容差分审计 |
| 组件版本 | 外层 DSP +0x38、CPU +0x50、RTOS +0x2038、CPU +0x90 均为 2.20.21.28 |
| 校验 | CPU 大端补数 +0x7c、decoded 尾部及容器尾部加和重算 |
| 后续恢复 | 基线 RTOS 0x536285dc：042803e3 → e6ffffea，跳往原成功返回 0x5362857c |
| 功能与资源 | 与已审计候选的其余 decoded 字节逐字节相同；不移植 2.20 原生功能 |
| 其他机型/2.10 | 不应用此差分，输出保持原路径 |
| API | native、edit、800T、历史候选 BIN 下载均经过同一最终适配；回执更新最终 SHA，保留适配前 SHA |
| 旧开关与桥接 | 2.20 来源不再显示旧 2.10 桥接；API 拒绝旧桥接和叠加单包版本适配 |

内部恢复更新器读取的是安装后的 2.10 代码，因此补丁使用 2.10 地址。第一包准入测试执行的是当前机内 2.20 更新器（入口 0x536285d0，DSP/CPU getter 0x53547c9c / 0x53547ce0）；不能用待刷入代码替代当前机内代码来证明第一包可刷。
