# GR3 5207 实验候选与验证说明

本款是独立的 M10V精选 `5207`（ID 66），基准为传统 5207、标准 ECN-2、中性扫描正片化。**不提供光晕，不执行 800T 红晕路径。** 旧目录 `V3 5207`（ID 64）保留兼容。

## 当前实现

- 离线模型与上游 MIT 来源位于 `third_party/spectral-film-lut/`。模型配置及逐文件来源摘要见 `native/gr3/5207-reference.json`；生成器为 `scripts/build_gr3_5207_reference.py`。
- 15³ uint8 RGB 3D LUT、定点四面体插值；按 4096 个固定随机留出样本计算，相对浮点参考的 ΔE00 中位数 0.326、P95 1.995。该数值不代表与真实胶片的相似度。
- 全部胶卷共享三档颗粒尺寸、四档颗粒强度；以 6000×4000 参考坐标维持输出尺寸间的尺度一致。程序化颗粒尚未以真实 5207 扫描的 RMS/频谱标定。
- 漏光强度 0–8、位置、范围、固定/随拍摄变化；默认关闭。所有胶卷均可调；5207 漏光在负片色彩变换前，其他胶卷在其色彩/柔光后应用暖色曝光近似，未做胶片漏光实测标定。柔光独立且默认关闭。
- v3 设置 104 字节、CRC32、双记录写后回读。读取有效 v2/v1 记录并迁移，不覆盖原记录；首次选择 5207 重置为颗粒弱、标准粒度、漏光/柔光关闭。
- 构建前核对上游/model 源摘要、C 与 Web LUT 实际内容；编译后及独立 Node 审计再核对嵌入的 table payload。

## 重要适用边界

当前入口为原厂 ISP 后、JPEG 编码前的 8bit CbCr422。参考模型暂以显示 sRGB 输入作假设，五个原厂槽位的输入统一和真实相机色彩校准仍待测量。不能恢复 ISP 已剪裁的高光。取景和机内 RAW 再开发尚未接入。

颗粒目前在烘焙的色彩响应后合成，是密度相关纹理的输出域近似。随机种子来自拍摄元数据与输入采样熵；相同输入和时间可能重复，不宣称已找到原厂逐帧计数器。6000×4000 颗粒尺度是工程参考，未证明等于某台扫描仪下的物理颗粒。

网页参数、host 渲染、ARM 模拟通过均不等于相机菜单、设备服务或 JPEG 实拍通过。当前没有真实 5207 与 GR3 的同场景冲扫标定，也没有 GR3 实机耗时或连拍测量；候选保持 `camera_tested=false`、`camera_calibrated=false`、`film_calibrated=false`。

## 复现构建

在项目虚拟环境安装 `native/gr3/5207-reference.json` 中记录的科学计算依赖。重新生成参考：

```sh
.venv/bin/python scripts/build_gr3_5207_reference.py
.venv/bin/python -m unittest tests.test_gr3_5207_reference tests.test_gr3_5207_assets
node scripts/export_gr3_m10v_native.mjs --debug builds/gr3-5207/debug builds/gr3-5207/configuration.json
```

候选依赖精确匹配的 GR III Street 2.10 官方包；其他型号/固件不能替换包头使用。调试版生成 SD 日志，以便核对每张使用的 film ID、颗粒/漏光值与 seed。

## 机内验证

保留并核对官方恢复包，按对应机型原厂升级流程处理候选。现有有效 M10V 记录优先于网页初始设置，所以安装后需要到 `MENU → Image Control → M10V Library → Choose Film → 5207` 明确选卷。

`Choose Slot` 指定承载槽。选择 5207 时，主菜单的效果项应为 `Light Leak`，不能出现 `800T Halation`。其子页有 Leak Gain、Leak Position、Leak Spread、Leak Variation、Reset Texture；Grain 与 Soft Diffusion 在主菜单独立设置；Grain Size 位于 Grain 子页。

依次测试五槽、浏览/确认/返回、重启恢复、重置、存储失败提示。先颗粒/漏光/柔光全关拍色卡、灰阶、肤色、天空与逆光，再分别只改变一项；对照 JPEG-only 与 RAW+JPEG。核对 RAW 像素未受胶卷处理影响，另测高 ISO、连续拍摄及日志中的实际快照。

最终胶片标定需要已知批次的传统 5207、受控 ECN-2 与固定扫描设置，拍摄与 GR3 相同的场景和曝光阶梯；留出独立场景，分别报告模型误差、输入归一化误差、色差与纹理误差。完成之前不得标称 100% 复刻。

## 通用质感与专属参数

网页只有一组颗粒（强度及尺寸）、柔光、漏光；按当前槽位保存。普通胶卷与 5207 均不显示光晕。800T 额外显示光晕强度、范围、阈值、档位。机内所有胶卷可在 Grain → Grain Size、Soft Diffusion、Light Leak 调整；仅 800T 有 Halation 入口。Reset Texture 只重置通用质感，保留胶卷及专属光晕。

逐 ID 回归覆盖 1–66（含历史记录胶卷），网页可见目录共 34 款。其他胶卷颗粒升级为共享参考坐标内核，以使粒度配置实际生效；漏光关闭且颗粒关闭时不额外转换像素。

## 本次自动验证结果

Python/ARM 共 107 项，106 项通过、1 项历史预期失败，无意外失败；Node 共 185 项，181 项通过、4 项跳过。最终 BIN 回读的真实 ARM 模块另通过全部 10 项捕获测试。独立复核发现并修复了漏光范围外的 RGB 剪裁改色问题，饱和颜色透传回归通过。375px 窄屏和桌面界面均已核对。以上不替代 GR3 实机验证。

## 与发布主分支整合

合入 2026-10-16 已发布的 800T energy / FN 详细菜单，保留 46 处已核对挂接。移除已弃用旧光晕渲染器的链接，保留原图标与编译优化方式。组合导出按实际扩展区与对齐计算长度，核对地址映射和实际内容。

104 字节 schema3 设置写入 M10V4A/B，避免覆盖已发布的 64 字节 M10V3A/B。后者保留现有 energy 参数迁移；旧 M10V2A/B 和早期 104 字节实验候选按关闭语义及 3/3/5 基准迁移，旧文件保留。网页去除旧 profile 档位，通过光晕强度 0 关闭；旧网页 profile0 同样迁移为 gain0。公共质感日志使用 130/131，避免与已发布诊断事件冲突。
