## 已确认并修复的黑屏原因

原厂 vtable 0x53d252d0 第12项 0x535948c4 是查询已打开句柄的大小，而非按路径查询。
其调用第21项 0x5359312c，后者在 0x53593168 读取 handle[1] 作为设备索引。
旧代码把 C:\M10V\FILMS.M10 作为第二参数，得到索引 0x5c563031；原厂 ARM 仿真在 0x5359317c 复现 UC_ERR_READ_UNMAPPED。
修复为先 open，再使用 handle 查询 size；所有非零句柄在查询/校验失败后也关闭。
新增测试执行两层原厂查询指令，仅替代 metadata 构造、互斥锁和设备叶子，覆盖正确读取、查询失败、空文件及释放。
旧 mock 未校验 size 第二参数，因而漏报这次 ABI 错误。已补上“必须是已打开句柄”的断言。
