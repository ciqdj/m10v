# GR III 官方原包 SD 更新准备验证（2026-10-11）

## 本地已验证

- 输入仅接受长度 30,391,780 字节、SHA-256 `d6a3c9c288d784080e7b283222ecdd8752adfeed6faa36dab44f73115354bfd4` 的官方 `fwdc239b.bin`。
- 服务端重新列举可移动、已挂载、可写且格式为 FAT/exFAT 的外部卷；HTTP 只接收设备标识，写前再次查询卷属性。目标为卡根目录的 `fwdc239b.bin`，已有同名文件则拒绝覆盖。
- 临时文件在目标卷写入并同步后，通过 macOS `/bin/mv -n` 做同卷、不可覆盖的最终发布；若目标竞争出现，命令保留临时文件，工作台据此拒绝成功并只清理自己拥有的临时文件，不删除竞争目标。这避免依赖 FAT/exFAT 不支持的硬链接。随后读取目标全部字节，核对长度和 SHA-256。发布、写入或回读失败不会返回 `official_sd_ready`。
- 注入的临时卷测试覆盖成功回读、已有文件、空间不足和回读不一致。接口测试覆盖令牌、Origin、设备选择与候选固件写卡路由关闭。
- 浏览器实测官方包导入与写卡区域渲染。当前 `diskutil list -plist external physical` 返回空数组，故未进行真实 SD 卡写入。

## 未验证与操作边界

- 真实 SD 卡的写入、拔出后复读、相机菜单识别和更新完成状态均未验证。
- 用户只有一台 GR III Street Edition 2.10。没有已验证的相机 Flash 镜像备份或硬件救援路径；电脑端官方包备份只能恢复本地文件。
- 版本门禁中的严格低版本拒绝已经静态定位；同版本包的整条验收路径尚未追通。修改版候选不提供 BIN 下载或 SD 写入。

## 有卡后的核验步骤

1. 在相机外备份卡上照片，插入要用于更新的可移动 SD 卡。
2. 在本机 Web 页面导入官方原包，刷新卷列表，核对设备标识和挂载名，再选择目标卡。
3. 点击“写入官方包到 SD 卡”；仅在页面显示 `official_sd_ready`、实际字节数和上述 SHA-256 后继续。
4. 安全退出卡，重新插入电脑复读根目录文件并核对完整 SHA-256。
5. 若准备在相机中更新，单独遵循理光官方 GR III 更新说明；记录相机菜单提示、版本与结果。电脑写卡通过不等于相机更新通过。
