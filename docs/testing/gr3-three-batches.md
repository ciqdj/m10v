# GR III 扩展实施记录（2026-10-13）

本记录按实际状态交付，不表示三批功能全部完成。用户明确将 GR IV 原包/激活表依赖后置。

## 已接入并可构建

- 原厂12预设图标、其中11预设英文名称；Standard名称只读，Custom1/2保留原配方。实际最大长度从源文件计算；借用其他语言空间时在预检回执列出语言编号。
- 内置负片颗粒菜单：9→10，追加原厂项0x0F。与其他功能共用从精确官方源重建的流程。
- 五个替换胶片各自颗粒0/弱/中/强；按稳定胶片ID和实际分槽映射，原厂值映射0/3/2/1。独立检查Vivid/Positive共享分支。
- RAW/Bayer降噪：原厂、关闭、经源表验证的ISO阈值。两个变体表和备用still路径检查，JPEG/LV不改。
- 完整Look/Profile XMP本地近似转换→sRGB目标→GR III矩阵/曲线拟合；不使用GR IV固件表，不声称重建Lightroom/Adobe基础相机配置。普通Develop、外部Stubbed Look和未支持内容拒绝；XML实体/DTD拒绝，色表解压限制32MiB。
- UI：稳定功能节点和选中胶片预览节点，Worker色彩预览，一次加载原图；快速切换时只排队最新一帧，像素循环减少临时分配且与旧算法逐字节一致。300ms保存合并，撤销/重做，取消真实Python/Worker处理，过期预检/拟合/图标导入不写回当前状态，reduced-motion支持。
- GRLife 2026-10-13 新增胶片库：m10v 将其作为独立五仓位方案接入当前锁定运行时；单独胶片模拟/时间戳互斥，Cross Processing 配方冲突阻断。官方 GR III 2.10 源上的胶片库＋滑轨水平仪已预检、构建并由 m10v 回读模块代码、十处固件站点、水平仪调用、RTOS/ICONBIN 范围和保护区。另一次胶片库＋画幅＋水平仪＋负片颗粒＋RAW NR 组合构建与审计通过。外部胶片库文件需要 GRLife 发放服务按机身授权码签发，m10v 不在本地生成或伪造；机内换片、持久化和实机显示尚未验收。

## 构建验证边界

新增原生修改仅RTOS/ICONBIN。源、配置、构建器/解析器/审计器相关代码摘要绑定到预检；从官方源重建，上游候选先独立容器检查，再按原字节前像叠加。类型字段、更新器/启动更新范围与版本字保护；叠加后所有非目标字节与base比较。名称/图标/负片菜单另外直接读实际指针、文字和像素，与用户配置语义核对，不仅信任writer的span/expected。

Python全量旧测试存在两条历史workflow断言，与现有多机型主页结构不匹配：test_page_exposes_actual_import_backup_and_locked_features、test_direct_file_open_keeps_styling_and_explains_server_requirement。主页及Python服务未由本次变更修改。原命令缺少-t .还会造成test_api/test_backup相对导入错误；应使用python -m unittest discover -s tests -t .。本记录不把该旧套件报告为全绿。

## 运行

npm start。原生名称/图标/负片颗粒/RAW NR无需GRLife核心；胶片/原有五功能需要锁定本地运行时。XMP需要现有.venv的numpy，默认.venv/bin/python3.12，可用M10V_XMP_PYTHON指定同等依赖的解释器。没有自动安装、上传或刷机动作。
