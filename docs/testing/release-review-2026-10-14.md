- 首页移除“仅在本机运行”、无操作价值的服务状态区及 local 字样；工作台移除 LOCAL WORKSPACE / LOCAL STUDIO。

## 发布状态与已确认阻塞

当前是完成上述修改的本地验证版本，未执行部署，不能直接宣称公网发布就绪。

1. `node/server.mjs` 固定只接受 `127.0.0.1:<port>` 的 Host，并默认绑定 loopback。以 `Host: example.com` 请求首页实际返回 403。需要明确部署域名、后端环境和访问策略后适配；不能只上传静态 web 目录。
2. 固件构建依赖 Node、Python、LLVM 和官方样本，部署环境必须提供这些依赖；此次未验证目标部署环境。
3. GR III / GR IIIx 的修改固件仍未完成真实相机的刷入、启动、菜单显示、持久化和拍摄验证。免责声明不能把离线检查升级为实机通过。

这些变化仅涉及网页保存交互和文案，未修改固件运行时。现有 v4 固件构建、校验与实机限制仍然有效。
