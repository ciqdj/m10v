# GR III Street Edition 2.10：更新路径与版本门禁方案

状态：**设计与离线证据；尚无可刷写候选。** 输入固定为 SHA-256 `d6a3c9c288d784080e7b283222ecdd8752adfeed6faa36dab44f73115354bfd4` 的官方 `fwdc239b.bin`，机身公开版本由用户确认是 2.10。

## 从代码得出的版本判断

RTOS 的更新状态在 `0x53838CD0` 调用 `0x536284E0`。后者按分区类型分支，读取候选外层 `0x38` 或 CPU 载荷 `0x90` 等版本字段，组装成 32 位版本值，与当前值作无符号比较。分支中的 `BLO` 拒绝严格较低值；相等值通过**这些比较**。分支表中 0/1 走外层版本，2/3/4 走双版本，5 在这个函数中直接成功，6 走 CPU 版本。返回失败时上层进入错误分支。复现方法见 `scripts/analyze_gr3_rtos.mjs` 和 `gr3-crop-shutdown-evidence.md`。

本机公开显示 2.10，用户说明装的是所给官方包；包内版本为 `2.10.21.27`。若机身的内部版本也确为该值，基于同包只改关机图片时不会被“低于当前版本”的 `BLO` 拒绝。公开显示 2.10 **不能单独证明**内部尾号相同，也不能证明同版本重刷被完整更新流程接受。**首选研究路线保留原版本，不补丁 `BLO`。** 待刷包中的 RTOS 补丁无法改变当前相机先执行的版本门禁；若要直接修改机身当前运行的分支，需要另有已验证的运行时/维修接口，本项目没有这样的证据或实现。

若后续实测发现同版本在另一门禁被拒绝，备选研究路线是基于同一 2.10 代码基线提高候选内部版本。离线计划至少须一致修改外层 `0x38`、`0x50`、RTOS `0x2038`、CPU `0x90`，并修复 CPU `0x7C` 的大端加和补数、整个解码区和外层容器的小端加和。还须证明机身当前**内部**版本、其它版本副本、分区/帧验收和相机接受规则。仅有这些算术修复不能证明新版本可刷入。

`scripts/probe_gr3_version_repack.py` 已在内存中将内部版本 `2.10.21.27` 试改为 `2.10.21.28`：四处版本字段回读一致，CPU `0x7C` 补数字由 `0x93800936` 变为 `0x93800935`，2,427 帧原样复用、3 帧转为 literal，独立解码与已知加和通过；试验容器为 30,425,660 字节。没有保存 BIN，也没有相机验收证据。这项试验验证的是**已知字段的算术与封包一致性**，不是更新流程准入。

## 最小实验候选的必要条件

第一候选仅针对 Street Edition `RES` 中 `Collabo.jpg`，保持 720×480、记录路径、资源计数及其它 34 条记录不变。应先验证相机可接受的 JPEG 编码与尺寸，再确定是否要求图片载荷等长；若保持等长，可将差异局限在一条资源及校验字。候选须从精确官方基线一次生成，并由独立解析器重新解码，核对目标资源、所有非目标字节、四处版本字段和每级加和。当前工作台不提供这条构建路径。

`scripts/probe_gr3_res_repack.py` 已做一项**内存中、不保存 BIN**的单字节试验：仅改动 `Collabo.jpg` 载荷中的一个字节并修复解码区校验字；2 个原帧换为 literal 帧，2,428 帧保持原编码，重新封装后独立解码逐字节等于预期，外层和解码区加和均为 0。试验容器为 30,395,352 字节，比原包多 3,572 字节。这证明当前编码器能构造自洽的电脑端试验数据，**不证明相机端帧大小、容量、JPEG 或更新验收兼容**。无改动重封装复现官方包也只证明容器封装的一个子集。

## 刷入前的实际门槛

1. 能从相机端或维修设备恢复固件的路径，须在这台设备或等效测试设备上验证；电脑保存官方 BIN 不能替代相机闪存备份。
2. 修改版 BIN 完成独立离线解码、完整性、差异白名单和关机资源回读；完整更新状态机和可能的额外校验被追踪到可解释的结果。
3. 首次实机测试使用可承受失败的测试机或具备救援工具的环境。记录更新阶段、版本显示、启动、拍摄、保存、回放、关机及再次启动结果。

只有满足这些门槛，才能把理光的[官方 GR III 更新流程](https://www.ricoh-imaging.co.jp/english/support/digital/gr3_s.html)作为**测试执行流程**：相机内格式化的 SD 卡、满电电池或适配器、BIN 位于卡根目录、关机按住 Menu 开机并在提示时执行更新。官方还警告更新中断会使相机无法使用。当前没有获准按此流程刷入的修改包；不能把进入更新菜单当作“已验证可安全刷入”。
