# M10V 精选 5207：调研与建议方案

日期：2026-10-16。状态：调研建议，待方案评审；未实现、未生成 LUT 或新固件、未做 GR3 实拍标定。

## 1. 已确定的目标

用户已选择：传统 35mm Kodak VISION3 250D 5207、标准 ECN-2、正常曝光、中性扫描正片化，LUT 由本项目调研选择。在“M10V精选”新增独立的 `5207`，提供颗粒、漏光等机内调节，参考 800T 的控制与集成方式。

以尽可能接近明确冲扫条件下的胶片成片为目标。不把“与某个 LUT 接近”换算成“与胶片相似百分比”。只有官网和 LUT 无法证明原生胶片 100% 复现；相机与胶片的光谱响应、曝光范围、镜头和冲扫变量都影响最终结果。此约束不降低校准要求，而是要求交付可以复核的误差和适用条件。

## 2. 官网资料的结论

- [Kodak 2022 年版 H-1-5207](https://www.kodak.com/content/products-brochures/Film/VISION3-250D-Technical-Data-EN.pdf)：日光 5500K、EI 250，标准 ECN-2，传统 remjet 背层；强调肤色、暗部细节和高光宽容度。含感光特性、光谱灵敏度、染料密度、MTF、RMS 颗粒曲线。
- [Kodak 2026 年版 H-1-5207](https://www.kodak.com/content/products-brochures/motion-picture/KODAK-VISION3-250D-5207-7207-technical-information.pdf)：已写明以防光晕底层替代传统 remjet。保留这份资料作版本差异记录，本项目所选传统版以 2022 年资料与对应胶片参考为准。

设计含义：优先还原中性阶、肤色分离、曝光变化中的色彩和高光过渡；不能预设固定青橙调色、大颗粒或强红晕就是 5207。漏光是额外曝光缺陷的创作模拟，默认关闭。官网“扩展两档高光宽容度”是胶片技术说明，不等于 GR3 滤镜可以恢复两档已截断信息。

## 3. LUT 与模型选择

| 候选 | 已核实的依据 | 本方案用途 |
| --- | --- | --- |
| [Spectral Film LUT](https://github.com/JanLohse/spectral_film_lut) 的 [5207 数据](https://github.com/JanLohse/spectral_film_lut/blob/main/src/spectral_film_lut/negative_film/kodak_5207.py) | 明确的 5207 模型，包含分通道感光曲线、光谱数据等；[MIT 许可](https://github.com/JanLohse/spectral_film_lut/blob/main/LICENSE)；作者承认公开数据和层间作用假设限制精度 | 推荐作离线参考模型和 LUT 生成起点，保留版权声明，固定提交与配置；必须对照传统版数据与实拍，不能当作 Kodak 官方 LUT |
| [Juan Melara FilmUnlimited](https://juanmelara.com.au/products/filmunlimited-flexible-film-emulation) | 作者说明拍摄并建模了 5207；模型基于 Alexa，机内 LUT 包含 2383 输出效果，公开支持列表未列 GR3 | 可作授权条件明确后的独立外观对照；本轮未购买、未下载商业文件，不内置其数据 |
| 仓库旧 `V3 5207` | 旧 GRLife 来源模拟目录中有该记录，矩阵/曲线已内置 | 保留兼容和对照，不改名后当作新版标定成果 |

选择的是可审计的参考模型，尚非已经验证优于所有商业 LUT 的结论。生成前必须核验 5207 数据出处、曲线横轴单位、曝光零点和密度定义。模型的 `year=2009` 元数据不能独自证明其数据对应传统版本。

生成流程：复核官方曲线 → 5207 负片响应 → 明确扫描光源/染料读出与负片正片化 → 固定中性灰、白点和显示变换 → sRGB 输出参考 LUT。中性扫描不能用“关闭印片”四个字代替完整扫描与反相定义；模型如仅提供印片流程，就单独实现并验证扫描读出模块。默认不叠加 2383。

参考阶段使用高精度浮点运算，比较 33³ 与 65³ LUT 的收敛误差；这是离线参考精度，不要求相机直接放入同尺寸表。冻结输入色域、传递函数、数据范围、白点适配、曝光基准、LUT DOMAIN、通道顺序和越界规则，同时保存源提交、配置、SHA256 和版权记录。本轮仅查阅作者资料与源码，未运行模型、未导出或测量 LUT。

## 4. 本轮从当前源码确认的现状

1. `node/gr3-native-library.mjs` 将前 33 项分为 M10V精选，但返回时筛选 ID >=33，实际精选仅显示 800T。旧 32 项对应 ID 34–65；`v3-5207` 是 ID 64。
2. `native/gr3/m10v_library.c` 中 800T 是 ID 33，使用简单 Y/CbCr 风格参数；只有 film==33 执行 halation。ID>33 则直接索引旧矩阵/曲线，不能把新增 ID 66 直接送入该分支。
3. 捕获桥输入为 JPEG 编码前、原厂 ISP 处理后的 8bit 半平面 CbCr422。五个承载槽的原厂 tone 为 12/18/19/20/21；现有资料明确未统一五槽 ISP 基底。不能假定输入就是标准 sRGB，更不能把它叫作 RAW 线性数据。
4. `node/gr3-lut-fit.mjs` 调用 `.runtime/grlife/.../film-fit.js`，其模型拟合原厂槽位的矩阵、分通道曲线与后矩阵；该模块的输入假设与当前保存 JPEG 上的叠加路径不同，不能不核验就共用输出参数。
5. 当前颗粒是 2×2 坐标分组的亮度伪随机噪声，不是经 5207 颗粒扫描拟合的模型；未见独立漏光参数和渲染路径。
6. 持久化为 v2、64 字节、五槽各 8 字节，使用 `M10V2A.bin/M10V2B.bin` 双记录、CRC 与写后回读。新漏光等参数需要版本化扩展，不能偷占保留字段改变旧语义。
7. 构建脚本当前代码链接预算为 64 KiB，代码/表/图标总映射预算为 512 KiB。历史重建 manifest 有 478560 字节记录，仅能说明当时体积，不能作为当前改动可容纳的证明。旧设计文档中的 60/64 KiB 总体积描述已不足以代表当前带图标的构建。

800T 的重建设计仍标记待评审、未实现；可复用已核验边界与接口，不能声称其新版算法、五项原厂详细菜单或完整机内操作已获验证。

## 5. 三条实现路线

| 路线 | 得失 | 建议 |
| --- | --- | --- |
| 直接拟合现有矩阵与曲线 | 接入快、表小；复杂局部色相响应受限，且不能解决五槽输入差异 | 仅作对照和测量基线 |
| 统一输入基底 + 专用 5207 3D LUT + 空间质感 + 实拍校准 | 保留已经建立的 JPEG 捕获边界，色彩表达能力更充分；仍受 8bit 和 ISP 截断限制 | 推荐 |
| 更早的线性 ISP/高位深处理 | 信息更充分；需要新的缓冲、生命周期与同步证据，显著扩大固件研究范围 | 后续独立研究，不作为本轮可直接交付的能力 |

推荐路线最重要的前置工作是验证五槽输入。用固定场景、固定 WB/曝光、关闭原厂附加效果，读取五槽进入 M10V 处理前的缓冲，检查范围、矩阵、传递特性和已发生的截断。优先在不破坏原厂调参语义的前提下，让 5207 使用经验证的一致基底。如果做不到，分别标定承载槽，并明确各槽可逆信息的范围；不能承诺用补偿矩阵恢复已剪裁颜色。

## 6. 建议处理链

`验证缓冲与拍摄快照 → 输入归一化 → 漏光附加曝光/镜头柔光 → 5207 负片响应 → 密度相关颗粒 → 中性扫描正片化/显示输出 → 时间戳 → 原厂 JPEG 编码`

工作 RGB/曝光域从已处理 8bit 数据重建时只是校准近似。漏光和光晕在胶片响应前合成，避免把调色后的白墙当成新光源；柔光按镜头散射建模，也在曝光阶段处理，不再在显示输出后重复添加。

首版明确为：归一化 → 漏光与镜头柔光 → 负片响应 → 颗粒 → 中性扫描输出 → 时间戳。先做可分阶段导出的高精度参考，再比较“合并色彩 LUT + 输出域颗粒”这一更省资源的近似；误差达标才接受合并。

### 色彩

- 固定 5207 主模型和标定参数，默认不提供任意滤镜混合强度，避免用户用降低强度补偿错误输入。
- 相机端先评估 17³、每点 RGB uint16 的定点 LUT（29478 字节）和四面体插值。33³ 同格式为 215622 字节，不预设能够放进现有映射。
- 17³ 若误差超标，比较 shaper + LUT 或稀疏残差；若仍不达标，则重新评审存储预算和映射。不能为保持旧体积而静默降低颜色精度，也不能直接扩大地址区。
- 原生矩阵/1D 曲线拟合仅作基线。新增色彩核统一 host 与 ARM 的插值、舍入和边界规则。

### 颗粒

以传统 35mm 参考扫描为准，使用多尺度、空间相关、密度相关的亮度与弱色度颗粒；拟合 RMS、功率谱、通道相关性及不同曝光下的幅度。颗粒大小按参考片幅和最终图像尺度换算，不把 APS-C 像素噪声直接当作 35mm 银盐颗粒。先记录参考画幅门尺寸；静态 36×24mm 与电影 35mm 画幅不能混用同一个颗粒尺度。

每张有独立 seed，同一输入和 seed 可以精确重放；连拍同秒不得重复同一纹理。ISO 100/低噪声输入是基础校准条件，高 ISO 另测传感器噪声叠加，不宣称能靠加颗粒消除数字噪声。

### 光晕、柔光、漏光

- 光晕：参考多尺度扩散结构，5207 独立弱响应配置，不继承 800T 的阈值和增益。不在本款传统 5207 中提供光晕入口或红晕处理；800T 的光晕仅服务 800T。
- 柔光：中性散射独立控制，默认关闭；不以强模糊冒充胶片 MTF。基础细节响应要另测原厂锐化与镜头影响。
- 漏光：边缘/角落进入的暖色附加曝光场，经过负片响应；采用有方向和尺度的低频不规则形态，不使用整幅红色透明蒙版。默认关闭；可锁定样式或逐张变换，固定种子可复现。

## 7. 建议机内参数

详细页沿用原厂负片颗粒的操作方式，参数是否可见由当前 film ID 决定，覆盖五个承载槽。参考 800T 的确认、取消、重置和拍摄快照流程，但新增实际处理与日志。

| 参数 | 范围 | 建议初始值/说明 |
| --- | --- | --- |
| 颗粒强度 | 关/弱/中/强 | 弱；具体幅度经扫描标定 |
| 颗粒尺寸 | 细/标准/粗 | 标准对应参考 35mm 尺度 |
| 漏光强度 | 0–8 | 0 |
| 漏光位置 | 左/右/上/下/角落/随机 | 左；强度 0 时不生效 |
| 漏光范围 | 0–8 | 中间档；强度 0 时不生效 |
| 漏光变化 | 固定/逐张 | 固定 |
| 柔光 | 关/弱/中/强 | 关 |

七项是分组详细设置的建议，不挤占原厂饱和度/色相/锐度；粒度、漏光和光学效果可各进入子页。提供“恢复 5207 标准”统一重置。预览与实拍均须消费同一参数定义，尚未接入的取景实时效果不能显示为已支持。

5500K 是基准照明与校准条件，不是强制所有场景锁 WB。首版说明中给出日光固定 WB 的可复现拍摄方式，AWB 和混合光源作为单独适用性测试。EI 250 不等于强制 GR3 ISO 250；以 GR3 原生低 ISO 建立基准，并按曝光阶梯测试响应。

## 8. 仓库接入与兼容

- 新增稳定 ID 66、key `m10v-5207`、显示名称 `5207`、分组 `M10V精选`。原 1–65 ID 不移动，旧 ID 64 `V3 5207` 保留兼容，可在描述中标明旧版来源。
- 改掉 film>33 即旧记录和菜单 index+33 的隐式映射，引入显式目录与 color/texture profile 分派。同步图标、字符串、菜单计数、配置边界、构建 manifest、HTTP 与审计，不只给网页加选项。
- 主要接入文件：`native/gr3/m10v_library.c`、`native/gr3/m10v_library.h` 及对应菜单/捕获/存储适配、新的 5207 色彩/颗粒/漏光模块、`node/gr3-native-library.mjs`、`web/gr3/native-library-state.mjs`、网页编辑器、`scripts/build_gr3_m10v_library.py`、`node/gr3-m10v-native-build.mjs`。
- v3 设置通过独立双记录保存，显式序列化并定义 CRC 范围，不依赖 C struct padding。迁移保留五槽 ID、800T 参数、质感和时间戳，新字段初始化后写入并回读；保留旧记录用于回退。首次选择 5207 时避免旧卷参数自动成为 5207 默认。槽位切换、同卷换槽的设置归属必须一致，首版按每槽保存覆盖值。
- 每张读取一次不可变快照，日志记录 film/profile、所有相关参数、seed、保存结果和渲染状态。分配失败在修改像素前退出；失效状态和存储错误需可见诊断。RAW 源区保护、跨度、别名、缓存和原厂编码调用契约继续逐项验证。
- 图标/表/代码各有预算；24MP 采用分块和有界 scratch，避免全幅浮点 RGB 临时缓冲。全部组合重新测耗时、连拍与峰值内存，不给出未经实机测量的延迟承诺。

## 9. 校准与验收

必须区分三类误差：模型与真实胶片的差异、相机输入归一化的差异、定点 LUT/空间核相对参考实现的差异。仅证明第三类很小，不能证明胶片还原准确。

1. **建立参考条件。** 使用有来源与批次的传统 5207，标准 ECN-2，保存扫描设备、光源/设置、分辨率、关闭自动调色/锐化/降噪等记录。固定中性扫描正片化方法，使用独立验证场景。若无法取得传统版，就不能拿 AHU 或去碳 C-41 样片替代后宣称传统版标定。
2. **同场景采集。** GR3 DNG+JPEG 与胶片拍摄色卡、灰阶/曝光阶梯、不同肤色、天空/植物/红色织物、逆光窗、反射与强光源；至少包括日光、阴天和 3200K，LED/混合光作为压力场景。固定光源、曝光和 WB，记录镜头/画幅差别。颗粒用多张均匀色块与密度阶梯，光晕用强度可控的点源和亮暗边界。
3. **分离拟合与验证。** 留出完整场景、光源和曝光作验证集，不把拟合所用色卡当全部结论。先仅校色，再加颗粒，最后独立测试光晕/漏光；关闭特效时不允许污染基础颜色。
4. **数值目标。** 对无颗粒参考 LUT 的相同输入，初拟工程目标为 ΔE00 中位数≤1、P95≤3、肤色≤2；逐项报告亮度/色域范围、色适应与越界样本。这是 LUT 近似目标，不是胶片实拍指标或相似百分比。真实胶片对照先测重复冲扫的误差底，再制定可达阈值；报告色差分布、灰阶曲线、高光色相和纹理频谱。
5. **链路与机内。** host/ARM 相同 seed 输出对照、各档调节方向、0 档关闭、分辨率缩放稳定性、边界/内存测试；真实 LCD 进入/调整/确认/取消/重置、五槽、重启恢复、每次只改一项的实拍；JPEG-only、RAW+JPEG、高 ISO 和连拍。核验 RAW 未被效果修改；不能用日志返回 0 代替成片验收。
6. **固件交付。** 从精确 SHA 官方 GR3 基线构建，独立回读挂钩、表和资源，检查其他分区与既有扩展、固件校验和、恢复路径；输出候选 BIN、manifest、参数与 LUT 来源、校准报告、机内操作说明和并排实拍。未实机验证始终标实验候选。

## 10. 建议推进顺序

先冻结参考色彩与 GR3 输入契约，再验证 3D LUT 能力/体积/耗时，随后接入颗粒和默认关闭的创作效果，再实现参数持久化与菜单，最后完成真实胶片和 GR3 的联合校准。输入基底如果未能统一，先解决这一问题，避免在错误颜色上反复打磨质感。

本次产出为调研与可评审方案。下一阶段依次交付：高精度参考与来源记录、GR3 输入/性能测量、候选实现与菜单证据、实拍校准结果。没有这些结果前，不声称已经达到 100%、已经机内生效或已经通过真实胶片标定。

## 执行修正

用户明确：5207 与 800T 不同，本款传统 5207 不添加光晕，不显示光晕控件。该约束覆盖上文早期的弱光晕设想；漏光、颗粒、柔光独立，800T 光晕路径仅服务 ID 33。相机端采用实测误差达标的 15³ uint8 LUT，为组合扩展和调试固件保留预算。

### 最终范围修正

颗粒、柔光、漏光是全库公共参数，不属于 5207 专属。800T 光晕作为专属参数独立提供；5207 不含该项。实现和验证细节以 `docs/testing/gr3-5207.md` 为准。
