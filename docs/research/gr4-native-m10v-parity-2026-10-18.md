# GR IV 原生 M10V 实现与验收记录

实现目标以当前 GR III 工作台、机内 M10V 入口与状态协议为准。GR4 独立使用官方 1.11 ABI，不复用 GR3 地址或结构体偏移。用户提供固件中的数据只作为逆向输入。

## 功能对应

| 功能 | GR IV 实现 | 验证边界 |
| --- | --- | --- |
| 五槽与36款胶卷 | 共用 GR3 颜色算法、LUT、图标与参数；GR4 自有36..40载体 | 原始 ARM 菜单调用、完整分辨率和成片测试 |
| 设置菜单 | 原生 TopMenu 所有权、创建/退出、按键翻译、恢复 | 原生构造/析构、列表与焦点执行 |
| 胶卷详情 | 逐胶卷支持的光晕、颗粒、柔光、漏光及 RED 曝光 | 原生 slider 生命周期与即时回调 |
| SD 换卷与保存 | 共享 FILMS.M10；104字节 A/B journal、CRC及回读后提交 | 无卡、损坏、短读、写入失败、重启恢复路径 |
| 时间戳 | 四种格式、四角、四色；日期/日期时间 | 本次拍摄时间、异常时钟回退；无效时间只跳过水印 |
| 机内图标 | 共用68款内部胶卷 artwork；颗粒尺寸使用GR3原始像素 | 最终BIN解包后逐像素比对69张图标 |
| 六位置配方 | 四原厂默认值和两个新位置；九参数 | 真正ARM默认值getter执行和资源回读 |
| 原厂名称/图标 | 20原厂风格独立路由，保留共享别名 | 独立名称、原图标/社区图标/自定义40×40 RGBA |
| 中央水平仪 | 同GR3滑轨；横/竖方向、颜色、隐藏与恢复 | 60组绘图命令及108组旋转角度对照原GR3模板 |
| 65:24 | 保留GR4原生四比例，新增65:24 | 原生裁切读回、RAW recut完整 |
| 负片颗粒 | GR4原生已有；校验原始映射与行准入 | 原始ARM执行，无重复修改 |
| RAW降噪 | 原厂、关闭、九档ISO阈值 | 真实mode0 getter/setup/mask执行；保留JPEG与取景降噪 |
| 网页 | /gr4/复用GR3工作台；官方导入/备份、草稿、方案绑定、预检、构建、SD导出 | 真实HTTP端到端与浏览器交互 |

胶片效果作用于保存的静态 JPEG；实时取景与机内 RAW 再开发沿用当前 GR3 的范围。独立配方/原厂预设模式与胶卷库模式的组合限制与 GR3 一致。原厂配方默认值需要在对应影像控制详细设置内重置参数后生效，网页会明确提示。

## 独立验证

- `python -m unittest discover -s tests -p 'test_gr4_*.py'`：当时75项全部通过，后续新增水平仪与配方另行验证。
- 最终水平仪11项、独立定制6项通过；原生模块覆盖记录见构建目录日志。
- `node --test --test-concurrency=2`：254项，250通过、4跳过、0失败。
- 完整BIN重新解包：原RTOS完全恢复、运行时代码哈希、184个文本descriptor、69张图标像素、水平仪模块及回调读回通过。
- 最终浏览器官方导入→确认→预检→完整构建→下载成功，截图保存在构建目录。配方六位置、原厂名称/图标和四项扩展同时启用的真实组合编译检查通过。
- 配套SD ZIP的CRC、36款清单、文件SHA及机内按键说明独立验证通过。
- GR3 renderer源与SD合同摘要未变。GR4构建仅在临时C翻译单元调整6256×4176尺寸上限，记录原源和编译源哈希。

最终固件与配置在 `builds/gr4-native-final/`，正式源仅接受指定官方1.11完整SHA。每个修改点锁定官方指令或目录preimage，构建失败不写最终产物。已保留工作区并行进行的GR3桥接变更。

## 真机验收

本机未连接 GR4，因此没有声称已完成刷入、LCD逐像素或传感器验证。离线验证不能证明真机100%一致。刷机后优先检查启动、MENU/OK/返回、五槽换卷、重启保存、拍摄JPEG+RAW、横竖构图水印、水平仪与比例切换；调试模式可在网页开启后重新构建并导出SD日志。
